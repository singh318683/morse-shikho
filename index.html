Morse code is made of two sounds: a short dit and a long dah. Each letter is a rhythm, like a tiny tune.

Don't count dots. Learn each letter as a sound, the way you recognise a word when someone says it. This app uses the Koch method: you hear letters at full speed from day one and add one new letter each time you reach 90%.

Send with the key

Press and hold the key (or your space bar). A short press is a dit, a long press is a dah. Pause to end a letter.
