# Morse Shikho

Learn Morse code by sound, from zero, with daily practice.

- **Learn** – Koch method: start with K and M at full speed, unlock one new character each time you score 90%+ (41 characters total).
- **Daily** – ~5 minute session weighted toward your weakest letters, plus words. Daily goal, 7-day history and streak.
- **Practice** – free drills with letters or words, your letters or all.
- **Send** – tap a telegraph key (or hold space) and the app decodes what you send.
- **Chart / Translate** – tap-to-hear reference and a text ↔ Morse translator.
- **Settings** – letter speed, Farnsworth spacing, tone pitch, volume, daily goal.

Plain HTML/CSS/JS, no build step. Progress is saved in the browser (localStorage).

## Deploy
Push to GitHub, import the repo in Vercel, keep the defaults (Framework: Other, no build command). Done.
